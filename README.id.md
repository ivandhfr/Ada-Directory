# Ada Directory JOSM Preset

[![en](https://img.shields.io/badge/lang-en-green.svg)](/README.md)

Preset penandaan JOSM untuk pemetaan di Indonesia. Saat ini berfokus pada **Kota Cirebon**, dengan pengisian tag alamat secara otomatis dan penggunaan istilah umum dalam bahasa Indonesia untuk menjaga konsistensi data.


## Mengapa Preset Ini Dibuat

Preset ini dibuat untuk membantumu menambahkan tag pada objek dengan lebih cepat dan konsisten, serta memberikan pengalaman penggunaan yang lebih baik dibandingkan preset bawaan JOSM.

| Fitur | Deskripsi |
|---------|-------------|
| **Pengisian tag alamat otomatis** | Cukup pilih kelurahan, maka tag kecamatan, kota, provinsi, dan kode pos akan terisi secara otomatis (saat ini hanya untuk Kota Cirebon). |
| **Penandaan dalam bahasa Indonesia** | Menggunakan istilah umum dan nilai yang telah ditentukan dalam bahasa Indonesia. |
| **Kategori yang lengkap** | Lebih dari 13 kategori POI, termasuk pendidikan, tempat ibadah, perdagangan, makanan dan minuman, layanan keuangan, logistik, stasiun energi, dan lainnya. |


## Instalasi

1. Buka **JOSM**.
2. Buka **Presets → Preset Preferences → +**.
3. Tempelkan `https://raw.githubusercontent.com/ivandhfr/Ada-Directory/refs/heads/main/Ada-Directory.xml` pada kolom **URL / File**.

## Penggunaan

Aktifkan preset Ada Directory di JOSM:

- **Pintasan keyboard**: Tekan **`F3`** (pintasan bawaan).
- **Menu**: Buka **Presets → Ada Directory**.

Setelah diaktifkan, preset akan muncul di panel **Presets**.


## Catatan Penting

**Proyek ini masih dalam tahap pengembangan.**

Selalu periksa kembali tag secara manual sebelum mengunggah data ke OpenStreetMap. Laporkan kesalahan atau ketidaksesuaian pada nilai preset melalui *issue* di repositori.


## Kontribusi

Setiap kontribusi berarti, baik berupa penambahan item baru, perbaikan tag, maupun penyempurnaan kecil. *Issue* dan *pull request* selalu terbuka untuk diajukan.

### Cara Berkontribusi

1. **Laporkan masalah** — Menemukan kesalahan atau item yang belum tersedia? Buat *issue*.
2. **Ajukan pull request** — Tambahkan item baru atau perbaiki tag dan ikon yang sudah ada.
3. **Periksa tag** — Pastikan tag sesuai dengan objek yang dimaksud dan mengikuti konvensi OpenStreetMap.
4. **Uji perubahan** — Pastikan preset berfungsi dengan baik di JOSM sebelum mengajukan perubahan.
