# Ada Directory JOSM Preset

[![en](https://img.shields.io/badge/lang-en-green.svg)](/README.md)
[![id](https://img.shields.io/badge/lang-id-blue.svg)](/README.id.md)

A JOSM tagging preset for mapping Indonesia. Currently focused on **Kota Cirebon** with automatic address tagging and standardized Indonesian terminology for consistent data.


## Why This Preset Exists

This preset is created to help you tag features faster and more consistent with improved user experience compared to JOSM default preset.
| Feature | Description |
|---------|-------------|
| **Automatic address tagging** | Select a *kelurahan* — *kecamatan*, city, province, and postal code will populate automatically (currently Kota Cirebon only). |
| **Localized Indonesian tagging** | Standardized terminology and predefined values in Indonesian. |
| **Comprehensive categories** | 13+ POI categories including education, worship places, retail, food & beverage, financial services, logistics, energy stations, and more. |


## Installation

1. Open **JOSM**
2. Navigate to **Presets → Preset Preferences → +**
3. Paste `https://raw.githubusercontent.com/ivandhfr/Ada-Directory/refs/heads/main/Ada-Directory.xml` in the **URL / File** column

## Usage

Activate Ada Directory preset in JOSM:

- **Shortcut**: Press **`F3`** (default)
- **Menu**: Navigate to **Presets → Ada Directory**

Once active, you'll see the preset appear in the **Presets** panel.
